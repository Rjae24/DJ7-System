# DJ7-System

Sistema de punto de venta (POS), inventario, gestión de compras, clientes, proveedores y reportes con integración a Supabase y cálculo de tasa de cambio (BCV / Paralelo).

## Tecnologías

- **Frontend:** React + Vite + Tailwind CSS / Vanilla CSS
- **Backend / Base de Datos:** Supabase (PostgreSQL & Auth)
- **Servicios:** API Tasa de cambio BCV
